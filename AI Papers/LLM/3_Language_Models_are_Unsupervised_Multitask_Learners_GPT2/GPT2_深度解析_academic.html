一句话总结

GPT-2 证明了一个令人震惊的假设：一个足够大的语言模型，在足够多样的文本上做单一的语言建模预训练，就能在没有任何任务特定监督的情况下（zero-shot），在多个 NLP 任务上达到有竞争力的表现。1.5B 参数的 GPT-2 在 8 个语言建模基准中的 7 个上以零样本方式达到 SOTA，揭示了"无监督多任务学习"作为通向通用语言智能的一条可行路径。

1. 研究背景与动机

1.1 2018 年 NLP 的两种范式

2018 年的 NLP 系统大致可归为两类。第一类是监督学习——为每个任务收集大量标注数据，训练专门的模型架构。这在单个任务上效果很好，但标注成本随任务数量线性增长。第二类是 GPT-1 开启的"预训练 + 微调"——先在大规模无标注文本上预训练，再在有标注的下游任务数据上微调。BERT 将这条路推向了极致，在 11 项任务上刷新了 SOTA。

但 OpenAI 团队看到了一个更深层的问题：预训练+微调仍然需要对每个下游任务收集标注数据。你能做情感分类、能做 NER、能做 QA——但每增加一个新任务，就要标注一批新数据。真实世界中，人类可以通过自然语言指令（"请把这段话翻成英文"）在不经过专门训练的情况下执行新任务。为什么语言模型不能？

1.2 核心假设

GPT-2 论文的核心假设大胆而简洁：所有的 NLP 任务都可以被表示为语言建模的子问题。翻译可以表示为"English: ... French: ..."的条件生成；问答可以表示为"Question: ... Answer: ..."的提示补全；摘要可以表示为"Article: ... TL;DR: ..."。如果一个足够大的语言模型在足够多样化的文本上训练——这些文本中天然包含了翻译对、问答对话、文章-摘要对——那么模型应该能在零样本条件下完成这些任务，只需给它一个合适的文本提示。

论文原话：

"We demonstrate language models begin to learn these tasks without any explicit supervision when trained on a new dataset of millions of webpages called WebText." (Abstract)

2. 方法详解

2.1 训练数据集：WebText

GPT-1 使用了 BooksCorpus（约 800M 词），这限制了训练数据的多样性和规模。GPT-2 创建了一个全新的数据集 WebText。构建方法：

  • 爬取 Reddit 上所有获得 ≥3 karma 的出站链接指向的网页
  • 经过 HTML 文本提取、去重、启发式清洗
  • 最终得到约 8 百万篇文档、40 GB 纯文本
  • 刻意移除了所有维基百科页面（因为许多下游任务的测试集源自维基百科，避免数据泄漏）

WebText 的关键特性不是"大"（40GB 在当时已经很大，但后来被 570GB 的 C4 等数据集超越），而是"多样化"——Reddit 用户链接的内容覆盖了翻译、问答、新闻、论坛、代码、食谱等几乎所有文本类型。正是这种多样性使得"无监督多任务学习"成为可能。

2.2 输入表示：Byte-Level BPE

GPT-2 使用 Byte Pair Encoding (BPE) 进行分词，但与标准的 Unicode BPE 有一个关键区别：它在字节级别操作，而非 Unicode 字符级别。标准 BPE 的词汇表包含所有见过的 Unicode 字符，遇到罕见字符时只能替换为 [UNK]。字节级 BPE 将每个 Unicode 字符编码为 1-4 个字节的序列，然后在字节序列上运行 BPE 合并——这保证了任何文本都能被精确编码，绝对不会出现 [UNK]。

最终词汇表大小：50,257 个 token（GPT-1 的词汇表基础 + 扩展）。上下文窗口从 GPT-1 的 512 扩展到 1024。

2.3 模型架构：Transformer Decoder 堆叠

GPT-2 的架构本质上是 GPT-1 的放大版 + 几项关键改进。它完全基于 Transformer Decoder——单向自注意力 + 位置-wise FFN：

2.4 相比 GPT-1 的架构改进

GPT-2 引入了几项虽小但重要的架构调整：

  1. Layer Normalization 前置（Pre-Norm）：将 LayerNorm 从子层的输出后移到子层的输入前。这个改动使训练更加稳定，尤其是对深层模型——它避免了激活值在深层传播时逐层放大或缩小。源码中清晰可见：attn(norm(x, 'ln_1'), ...) 和 mlp(norm(x, 'ln_2'), ...)。
  2. 残差权重的深度缩放：初始化时残差层的权重乘以 $1/\sqrt{N}$（$N$ 为层数）。这使得在深度增加时，残差分支的初始贡献保持恒定，防止深层梯度爆炸。
  3. 最终层归一化：在所有 Transformer 层之后添加额外的 LayerNorm，确保输出进入语言模型头之前有统一的数值分布。

核心 Transformer Block 的源码（`model.py:123-130`）精确反映了这三项改进：

# model.py:123-130 — block function (the core building block)
def block(x, scope, *, past, hparams):
    with tf.variable_scope(scope):
        nx = x.shape[-1].value
        a, present = attn(norm(x, 'ln_1'), 'attn', nx, past=past, hparams=hparams)
        x = x + a                                    # residual add after attention
        m = mlp(norm(x, 'ln_2'), 'mlp', nx*4, hparams=hparams)
        x = x + m                                    # residual add after FFN
        return x, present

注意 norm(x, 'ln_1') 在 attention 之前而非之后——这就是 Pre-Norm 的具体实现。相比 Transformer 原论文的 Post-Norm（$x + \text{Sublayer}(\text{Norm}(x))$），Pre-Norm 在深层网络的训练稳定性上具有显著优势。

2.5 自注意力中的因果掩码

作为 Decoder-only 架构，GPT-2 的自注意力使用因果掩码保证每个 token 只能看到它之前的 token。源码中的掩码构建非常优雅：

# model.py:58-66 — attention_mask (causal mask)
def attention_mask(nd, ns, *, dtype):
    i = tf.range(nd)[:,None]     # destination positions [nd, 1]
    j = tf.range(ns)              # source positions [ns]
    m = i >= j - ns + nd          # lower-triangular: only past + self
    return tf.cast(m, dtype)

# model.py:91-99 — multihead_attn (scaled dot-product)
w = tf.matmul(q, k, transpose_b=True)   # QK^T
w = w * tf.rsqrt(d_k)                   # scale by 1/sqrt(d_k)
w = mask_attn_weights(w)                # apply causal mask
w = softmax(w)
a = tf.matmul(w, v)

几个反直觉的发现值得深究：

  • LAMBADA 的巨幅提升：LAMBADA 是一个"读完一段话、预测最后一个词"的任务——需要理解整段文本的叙事逻辑。此前 SOTA 使用了专门的架构和训练策略，但 GPT-2 仅靠零样本语言建模就将准确率推到了 63.24%。这说明 1.5B 参数的模型自发地学会了某种长程叙事推理。
  • 儿童图书测试 (CBT)：93.3% 的准确率意味着 GPT-2 能在 20 个候选项中选出正确的词来完成一个儿童故事。这个任务需要常识性推理——"猫通常吃什么？"——GPT-2 几乎没有犯低级错误。

3.2 零样本任务迁移——真正的"多任务学习"

这部分是 GPT-2 论文最令人震撼的贡献。作者没有对任何下游任务进行微调——模型看到的只有语言建模损失。但当你给它一个适当的提示（prompt），它就开始执行任务：

这里的发现呈双面性：在那些"从已有知识中提取"的任务（如 Winograd 常识推理、CoQA 阅读理解），GPT-2 的表现出人意料地好——甚至超越了此前有监督训练的专门模型。但在那些需要"精确复制或转换"的任务（如翻译、摘要），零样本表现与有监督方法差距巨大。

这个模式揭示了 GPT-2 学习方式的本质：它在 WebText 中见过大量的问答对话、推理链和知识陈述，因此能"回忆"这些模式；但它没有被显式训练去精确对齐原文和译文，因此翻译和摘要能力很弱。

3.3 规模与性能的关系

论文的一个核心实证发现是：随着模型规模的增长，零样本任务性能呈平滑的对数线性增长。跨越 117M → 345M → 762M → 1.5B 四个数量级，语言建模困惑度持续下降，且没有任何饱和的迹象。这意味着继续扩大模型规模——扩展到 10B、100B、甚至 1T 参数——很可能会继续带来性能提升。

这正是 OpenAI 后续 GPT-3（175B）工作的直接动机。GPT-2 的规模曲线是说服 OpenAI 投资训练 GPT-3 的最重要的单个数据点。

4. 泛化 vs 记忆——数据重叠分析

一个自然的质疑是：GPT-2 的零样本能力是不是因为它"背"下了测试数据？作者通过一个 8-gram 重叠分析来回答这个问题：

  • 测试集与 WebText 的 8-gram 重叠率约 1-6%（因任务而异）
  • 移除重叠文档后重新训练（小规模模型），性能下降微小但可测
  • 重叠率与性能没有显著的正相关

这说明虽然存在一定程度的数据污染（在大规模网页数据中几乎不可避免），但 GPT-2 的大部分零样本能力确实来自泛化，而非记忆。

5. 讨论与局限

作者自述的局限 1——生成能力远弱于理解能力：GPT-2 在需要精确复制或转换文本的任务（翻译、摘要）上的零样本表现与有监督方法差距仍然很大。作者明确指出"当前方法在这些任务上的表现还远未达到实用水平"。

作者自述的局限 2——语言建模目标与任务目标不总是一致：语言建模优化的是"下一个 token 的概率"，而摘要需要的是"压缩后的核心信息"。这两种目标存在内在张力——最好的语言模型不一定是最好的摘要模型。

独立判断——提示工程的黑箱性：GPT-2 的零样本性能对提示格式极其敏感。"English = French" 和 "Translate English to French:" 可能给出截然不同的 BLEU 值。这种提示敏感性在后续 GPT-3 中进一步放大，引入了"提示工程"这个全新的、半经验性的研究子领域——也带来了可复现性的挑战。

独立判断——计算成本的伦理和政治维度：GPT-2 论文最初因"可能被用于生成虚假新闻"而只发布了 117M 的小模型，1.5B 模型延迟了 9 个月才发布。这场"负责任发布"的讨论引发了 NLP 社区对开放科学、安全性和集中化趋势的长时间辩论。

6. 结论——GPT-2 留下的范式转移

GPT-2 的核心贡献是用实证方式证明了一个直到当时仍被视为推测性的假设：无监督语言建模可以自然涌现出多任务能力。它没有为翻译、问答、摘要设计任何专门的训练目标或架构——却在这些任务上取得了可观的零样本表现。

这个发现直接改变了 NLP 的研究方向。"预训练 + 微调"（BERT 范式）在 2019 年是主流，但 GPT-2 暗示了另一条更激进的路线："预训练 + 提示"——完全跳过微调，通过精心设计的自然语言提示直接让模型执行任务。GPT-3 将这条路线推到了极致（175B 参数、few-shot 提示），而 InstructGPT/ChatGPT 进一步通过 RLHF 将零样本能力对齐到人类意图。

从 GPT-2 到 ChatGPT 的演进路线中，有一个核心思想始终一致，它是 GPT-2 论文最先清晰表达的：语言模型的能力边界不由架构限制，而由训练数据的规模和多样性决定。这个洞见至今仍是 LLM 研究最根本的指导原则。
