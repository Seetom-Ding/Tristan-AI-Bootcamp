一句话总结

PlaNet 提出了 Recurrent State-Space Model (RSSM)——一种结合确定性循环路径和随机路径的隐动力学模型——配合 latent overshooting 训练目标，首次实现了从像素输入进行快速在线规划（MPC）的模型基 RL，样本效率比 A3C 高出 5000 倍。

核心数字速览

核心架构RSSM = 确定性 RNN 路径 + 随机状态路径，在隐空间交叉
规划方法Cross-Entropy Method (CEM) + Model Predictive Control (MPC)
样本效率比 A3C 少 5000× 环境交互（部分任务）
关键训练技巧Latent Overshooting — 同时预测未来 1~N 步的隐状态

1. 从 World Models 到 PlaNet——"做梦不够，要规划"

World Models 证明了 latent dynamics 的可行性，但其 MDN-RNN 在长期预测中累积误差严重——"梦境"在几步之后就偏离真实。PlaNet 通过两个核心创新解决了这个问题：① 将纯随机模型 (MDN-RNN) 升级为混合型 RSSM（确定性+随机路径），大幅提升了长期预测精度；② 用规划（MPC）替代梦境内训练——不再预先训练一个控制器，而是在每次决策时通过 RSSM 在隐空间中快速模拟多条未来轨迹并选择最优路径。

2. RSSM——确定性火车 + 随机乘客

RSSM 的核心设计理念：确定性部分（RNN）负责建模环境的"大势"——那些平滑、可预测的动态；随机部分负责建模"细节"——那些多模态、不可精确预测的偶然变化。

形式化表示：

$$\text{Deterministic state: } h_t = f(h_{t-1}, s_{t-1}, a_{t-1})$$ $$\text{Stochastic state: } s_t \sim p(s_t \mid h_t)$$ $$\text{Observation: } o_t \sim p(o_t \mid h_t, s_t)$$

这就像天气预报——RNN 部分预测"趋势"（明天冷锋南下），随机部分注入"噪声"（具体的云层分布是概率性的）。

3. Latent Overshooting——"不只预测下一步，还要预测未来 N 步"

标准 RNN 训练只看一步预测损失。PlaNet 的关键创新是同时优化多步预测——通过一个改写的变分下界，对从当前时刻到未来 N 步的隐状态序列同时施加约束。这迫使 RSSM 学会一致而准确的长程动力学——对于 MPC 规划至关重要。

在连续控制任务上（如 Cheetah Run, Walker Walk），PlaNet 以 远少于 A3C/DDPG 的环境交互次数达到了相当或更好的性能——在某些任务上样本效率差距达到三个数量级。

4. 局限与影响

局限 1——CEM 规划的计算瓶颈： 每次动作选择需要模拟数千条轨迹，实时性受限。

局限 2——显式奖励需建模： PlaNet 额外训练了一个奖励预测器，增加了系统的组件数量。

PlaNet 的 RSSM 架构被直接继承到 Dreamer 系列中——Dreamer 将"规划"升级为"潜空间反传梯度优化"，进一步提升了效率和终态性能。
